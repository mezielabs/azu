# Changelog

Both packages version and release together. Dates below describe publication, not implementation.

## 0.1.0-preview.0 — Unreleased

First preview candidate. Nothing has been published by preparing this entry. The API may change before a stable release.

### Added

- AdonisJS installation/configuration with a separate admin entry and a default-deny access ability.
- Typed Lucid resources and generated validators/policies; lists, forms, detail screens and filters.
- VineJS validation and server-side Bouncer checks for routes, fields and actions.
- Relationship pickers, rich text, Drive uploads, row actions and bulk actions across all matching records.
- Light/dark theming, navigation groups/icons/order, component overrides, slots, page publishing and drift diagnostics.
- Custom screens, settings forms, and value, partition and table widgets with date ranges.

### Preview boundaries

- Release verification, owner approval, npm configuration and publication are still required.
- Further review fixes belong in this entry when merged into the release candidate; open PRs are not claimed as shipped.
