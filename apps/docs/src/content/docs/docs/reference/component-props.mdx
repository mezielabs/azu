Your components get typed props. Import the types from `@mezielabs/azu-react`. They're defined in `@mezielabs/azu`, so a future Vue package can share them.

## FieldProps

For a field's component: `field.text('sku').component('SkuInput')`.

```ts
type FieldProps<Value = unknown> = {
  value: Value | null
  onChange: (value: Value | null) => void
  errors: string[]
  field: {
    name: string
    label: string
    /** Required state inferred from the validator */
    required?: boolean
  }
  /** The form's other values */
  record?: Record<string, unknown>
}
```

## CellProps

For a column's component: `column.custom('stock', 'StockBar')`, or `.component('Name')` on any column.

```ts
type CellProps<Value = unknown> = {
  /** The cell's value, as the column kind serialises it */
  value: Value | null
  /** The row: its id, title, every cell's value, and what the user may do with it */
  record: ListRow
  column: ColumnSchema
}
```

## SlotProps

For a component in one of a resource's [slots](/docs/guides/customising/#slots).

```ts
type SlotProps = {
  resource: ResourceSchema
  page: 'index' | 'create' | 'edit' | 'show'
  /** The record being edited or shown; null on the list and create pages */
  record: { id: string | number; title: string | null } | null
  /** The resource's list URL, e.g. /admin/resources/products */
  path: string
}
```

## ScreenProps

For a [screen's](/docs/guides/screens/) component. Pass the screen's type, and `data` is typed from its `data` function.

```ts
type ScreenProps<S extends Screen<any> = Screen<unknown>> = {
  data: S['__data']
  screen: ScreenSchema
}
```

`screen` is the screen's schema: its name, label, and the rest of what the navigation shows. The demo's `SalesReport` component is on the [Screens](/docs/guides/screens/#the-component) page.
