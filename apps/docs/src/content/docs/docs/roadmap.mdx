Azu is early. This page separates available features from plans. Planned scope and timing can change; use the installation and reference guides for current behaviour.

## Built, in the preview

`0.1.0-preview.1` has been on npm since 9 November 2026 (`0.1.0-preview.0` since 3 November). It has:

- Resources, fields, and relationships (`belongsTo`, `hasMany`, `manyToMany`).
- Permissions and validation, from your policies and validators.
- Row and bulk actions, including on all filtered rows.
- Filters, form sections, and list column choices.
- Theming, navigation groups, and icons.
- Component overrides, slots, and `azu:publish`.
- Screens: your own screens, navigation links, a home screen, screen forms, widgets, and trends.

[Preview limits](/docs/preview-limits/) lists the known gaps in the current release.

## Next

These are planned improvements, without committed delivery dates:

- Private disks for uploads, with signed URLs.
- Soft deletes, with a trashed filter and restore.
- Global search.
- Azu's own interface in other languages, through AdonisJS i18n. It's English-only for now.
- Navigation badges, and more override slots.
- v1.0.
- Azu Pro.
- Vue support, if there's demand.

## Azu Pro

The core is free and MIT licensed, and it always will be. Azu Pro is a planned set of paid extensions. The proposed scope includes:

- **Audit log:** every admin change, with before and after values.
- **CSV import and export**, with a validation preview before anything is saved.
- **Impersonation**, so support staff can see exactly what a user sees.
- **Multi-tenancy**, with automatic query scoping.
- **Premium layouts and theme.**

The licensing plan offers per-project and unlimited-project options, with install-time checks rather than runtime checks. These are plans for an unreleased product; consult its published terms when it becomes available.

## Contributing

The most useful contribution right now is feedback on the API. Open a [discussion](https://github.com/mezielabs/azu/discussions) with what you'd change, or with what your current admin does that Azu wouldn't.
