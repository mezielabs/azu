## Name and logo

- `brand.name` (default "Admin") shows at the top of the sidebar and in page titles.
- `brand.logo` is an image shown before the name. Without one, the sidebar shows a tile with the name's first letter.

## Colour

`brand.color` is a hex colour, `#2563eb` by default. Azu uses it as is wherever it's readable.

Where it isn't, Azu shifts only the colour's lightness, so the hue stays. It shifts it until all text reaches WCAG AA (4.5:1) on each theme's backgrounds.

So the exact hex on screen may differ from `brand.color`, and from light mode to dark mode. A very light brand colour gets darker on the light theme, for example. The demo's clay, `#b0472a`, is 5.6:1 on white, so the light theme uses it as is. On the dark theme it's 3.6:1, so Azu lightens it there.

Text on brand-coloured buttons is white or near-black, whichever reads.

Note: errors, success messages, and badges keep their own colours. A red or yellow brand can't make them unreadable.

## Light and dark

Dark mode follows the user's system setting. That's **System**, the default.

**Light** or **Dark** in the account menu overrides it, and the browser remembers the choice. **System** forgets it and follows the system again, live.

## CSS variables

The palettes are Azu's own CSS variables, set on `<html>`: `--azu-brand`, `--azu-surface`, `--azu-text`, and so on. Use them in your own components to match the theme. The demo's stock bar uses `var(--azu-danger)`.
